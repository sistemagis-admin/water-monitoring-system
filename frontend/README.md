# Water Monitoring System (Sistem Monitoring Pompa Air)

Sistem dashboard monitoring dan kendali real-time untuk stasiun pompa air berbasis Web/IoT.

## Fitur Utama
- **Real-time Telemetry**: Monitoring level air, flow rate, pressure, daya, dan getaran secara langsung.
- **Kendali Motor Pompa**: Kontrol status motor pompa (Main & Auxiliary) dengan visualisasi status interaktif.
- **Safety Emergency Stop**: Modal konfirmasi darurat untuk menghentikan seluruh pompa secara aman dan instan.
- **Trend Charts & Analytics**: Grafik analitik riwayat parameter level air dan flow rate real-time.
- **Light & Dark Theme**: Dukungan mode terang dan gelap dengan transisi halus.
- **Responsive & Modern UI**: Desain dashboard industrial yang intuitif dan responsif.

## Tech Stack
- React 19 + TypeScript
- Vite
- Tailwind CSS
- Lucide React (Icons)
- Chart.js / SVG Visualizations

## Menjalankan Proyek Secara Lokal

1. Clone repository:
   ```bash
   git clone https://github.com/sistemagis-admin/water-monitoring-system.git
   ```

2. Masuk ke direktori:
   ```bash
   cd water-monitoring
   ```

3. Install dependensi:
   ```bash
   npm install
   ```

4. Jalankan development server:
   ```bash
   npm run dev
   ```
